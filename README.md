# Клёвое место — рыбалка

Браузерная игра-рыбалка для платформы MAX, горизонтальный экран. Запускается через `index.html`.

## Что внутри

- 7 водоёмов: пруд, лесная река, озеро, болото, горная река, Волга, Карелия. У каждого свой фон (день, вечер, ночь), своя музыка и звуки природы.
- 35 видов рыб, включая легендарных (золотая рыбка, белуга) и краснокнижных (их только отпускают).
- 3 типа снастей: поплавочная удочка, фидер с прикормкой, спиннинг. Всего 12 удилищ, 5 катушек, 6 лесок, 5 размеров крючков, 16 наживок, 11 приманок, 6 прикормок.
- Вываживание с натяжением лески, фрикционом, перегрузом удилища, сходами и прыжками рыбы.
- Время суток, погода и атмосферное давление, активные точки на воде, эхолот, мусор и клады.
- Задания, достижения, атлас рыб, ежедневный подарок, рейтинг (общий вес улова).

## Структура

```
index.html        — разметка, SVG-иконки
css/style.css     — оформление
js/manifest.js    — список всех ресурсов для загрузчика (генерируется)
js/data.js        — рыбы, водоёмы, снасти, баланс
js/core.js        — вёрстка, сохранения, MAX SDK, рейтинг, шаринг
js/loader.js      — загрузка всех ресурсов с полосой прогресса
js/audio.js       — звук: Web Audio, музыка и атмосфера
js/fishing.js     — механика рыбалки
js/scene.js       — отрисовка на canvas
js/ui.js          — экраны и окна
js/main.js        — события, игровой цикл, запуск
assets/           — фоны, рыбы, иконки, текстуры, шрифты, музыка, звуки
tools/            — генераторы ресурсов на Python (numpy + Pillow + ffmpeg)
```

## Пересборка ресурсов

```
pip install numpy pillow
cd tools
python3 gen_bg.py && python3 gen_fish.py && python3 gen_items.py && python3 gen_ui.py
python3 gen_audio.py
python3 gen_manifest.py
```

Папка `tools/` для работы игры не нужна.
